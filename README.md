# SeaPath ECDIS

> **Профессиональный навигационный комплекс автоматизированной предварительной прокладки маршрутов с учетом батиметрии, динамического запаса под килем (DUKC), кинематики судна и векторных фарватеров (S-57/ENC)**

SeaPath — это высокопроизводительная судовая навигационная система предварительной прокладки перехода (Passage Planning) в прибрежных, стесненных и мелководных районах плавания. Комплекс объединяет региональные матрицы батиметрии высокого разрешения (модель EMODnet DTM), гидродинамические формулы скоростного проседания судна (squat effect), кинематические ограничения циркуляции и поворотов судна, нативное расчетное C++ ядро и векторные коридоры судоходных фарватеров и систем разделения движения (TSS).

---

## Ключевые возможности

- **Высокопроизводительное C++ нативное ядро (`seapath_native`)**:
  - Реализовано на современном стандарте C++17 с привязками `pybind11`.
  - Ускорение поиска пути в **35 раз** по сравнению с интерпретируемой версией Python (расчет транс-регионального маршрута через Черное море за ~5.5 мс).
  - Пул плоской памяти нулевой аллокации между последовательными запросами, битовые маски и быстрый лучевой алгоритм Брезенхема.
  - Двухрежимная архитектура: автоматическое подключение нативного C++ модуля с прозрачным фоллбэком на оптимизированный Python.

- **Кинематика судна и радиусы циркуляции (Ship Kinematics)**:
  - Штраф за изменение курса (Heading Alteration Penalty) в процессе поиска пути $A^*$: исключение неестественных ломаных зигзагов и резких курсовых скачков.
  - Моделирование точек начала поворота (Wheel-Over Points) и сглаживание углов круговыми дугами циркуляции судна с проверкой непрерывного клиренса по дуге.
  - Поддержка параметров маневренности для малых яхт (R=50м), паромов Ro-Ro (R=250м) и крупнотоннажных судов (R=500м+).

- **Векторные фарватеры и навигационные ограничения (S-57 / ENC)**:
  - Интеграция базы векторных фарватеров (`FAIRWY`), полос систем разделения движения (`TSSLPT`/`TSSRON`) и дноуглубленных каналов (`DRGARE`).
  - Коэффициент аттракции: привлечение судов в оборудованные безопасные фарватеры и глубоководные морские магистрали.
  - Строгое обжалование и предотвращение захода в зоны опасности и ограничения (`RESARE`): полигоны боевой подготовки, заповедные морские зоны и районы затонувших судов.

- **Динамический запас под килем (DUKC)**:
  - Расчет динамического проседания корпуса на ходу по открытой формуле Баррасса ($\Delta h = \frac{C_b \cdot V^2}{100}$) в реальном времени.
  - Учет статической осадки, скорости хода и нормативного эксплуатационного запаса UKC.

- **Таблица плана перехода (Passage Plan) и экспорт (GPX & RTZ)**:
  - Автоматическая генерация структурированной таблицы путевых точек (WP): истинные путевые углы ($\degree\text{T}$), дистанции плеч перехода (NM), углы изменения курса ($\degree$), глубина под точкой и фактический запас под килем.
  - Экспорт в международный формат **RTZ 1.1 (IEC 61174:2015 Annex S)** для загрузки в коммерческие судовые ЭКНИС (Furuno, Kongsberg, Wärtsilä/Transas, JRC, Raytheon).
  - Экспорт в стандартный формат **GPX 1.1** для портативных и любительских картплоттеров (Garmin, Raymarine, OpenCPN, Navionics).

## Гидродинамические формулы и функция стоимости

### 1. Скоростное проседание судна (Squat Effect)
Проседание корпуса судна на ходу в открытой воде рассчитывается по зависимости Баррасса:

$$\Delta h = \frac{C_b \cdot V^2}{100}$$

Где:
- $\Delta h$ — динамическое проседание (в метрах);
- $C_b$ — коэффициент общей полноты корпуса (Block Coefficient, по умолчанию $0.60$);
- $V$ — скорость относительно воды (в узлах).

Минимальная безопасная глубина акватории:

$$D_{\text{min}} = T_{\text{static}} + \Delta h + \delta_{\text{UKC}}$$

### 2. Функция стоимости перемещения
Стоимость шага $A^*$ штрафует приближение к критической изобате, отклонение от фарватеров и крутые повороты:

$$\text{Cost} = \left( C_0 \cdot \left( 1.0 + \frac{8.0}{\max(0.05, D - D_{\text{min}})} + P_{\text{deep}} \right) \cdot W_{\text{fairway}} \right) + P_{\text{heading}}$$

Где:
- $C_0$ — базовая евклидова стоимость шага (1.0 для кардинальных направлений, $\sqrt{2}$ для диагоналей);
- $W_{\text{fairway}}$ — весовой модификатор ($0.35$ внутри фарватера/TSS, $1.0$ в открытом море, $\ge 500$ в запретных зонах);
- $P_{\text{heading}}$ — кинематический штраф за резкое изменение направления движения относительно входящего вектора скорости.

## Установка и запуск

### Требования
- Python 3.10+ (64-bit)
- Компилятор C++17 (MSVC на Windows или GCC/Clang на Linux)
- Зависимости `rasterio`, `pybind11`, `fastapi`, `uvicorn`

### 1. Клонирование и виртуальное окружение
```bash
git clone https://github.com/EugeneBarinov/sounder-path.git
cd sounder-path

python -m venv venv
# Windows (PowerShell):
.\venv\Scripts\Activate.ps1
# Linux / macOS:
source venv/bin/activate

pip install -r requirements.txt
```

### 2. Сборка нативного модуля C++
```bash
python setup.py build_ext --inplace
```

### 3. Бенчмарк производительности
Для сравнения производительности нативного ядра и Python-версии:
```bash
python scripts/benchmark.py
```

### 4. Запуск сервера
```bash
uvicorn backend.main:app --host 0.0.0.0 --port 8000 --reload
```
Откройте веб-браузер по адресу `http://localhost:8000`.

## API сервиса

### `POST /api/route`
Расчет безопасного маршрута с учетом батиметрии, кинематики, фарватеров и DUKC.

**Тело запроса (JSON):**
```json
{
  "start_lon": 33.36,
  "start_lat": 45.18,
  "goal_lon": 33.50,
  "goal_lat": 44.62,
  "draft": 2.0,
  "speed_knots": 12.0,
  "ukc": 0.5,
  "turning_radius_m": 150.0,
  "fairway_preference": 1.0
}
```

### `POST /api/export/gpx`
Экспорт рассчитанного плана перехода в стандартный файл GPX 1.1.

### `POST /api/export/rtz`
Экспорт рассчитанного плана перехода в международный стандартный формат IEC 61174 RTZ XML для ЭКНИС.

### `GET /api/fairways`
Возвращает векторные полигоны фарватеров, полос движения СРД и зон ограничений (GeoJSON).

### `GET /api/grid`
Возвращает полигон границ покрытия загруженной батиметрии (GeoJSON).

### `GET /api/health`
Проверка состояния сервиса и габаритов активной сетки.
