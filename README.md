# SeaPath ECDIS

> **Автоматизированная система прокладки маршрутов с учетом батиметрии и динамического запаса под килем (DUKC)**

SeaPath — это специализированный навигационный комплекс предварительной прокладки маршрута перехода (Passage Planning) в мелководных и стесненных районах. Система объединяет региональные матрицы глубин высокого разрешения (модель EMODnet DTM), гидродинамические формулы скоростного проседания судна (squat effect) и эвристический алгоритм оптимизации пути ($A^*$ с лучевым сглаживанием прямой видимости string-pulling) для построения безопасных судоходных фарватеров.

---

## Основные возможности

- **Батиметрический движок**: Прямая загрузка растровых сеток GeoTIFF, инверсия отрицательных отметок батиметрии, валидация системы координат (EPSG:4326), маскирование суши и консервативный даунсэмплинг (выборка локального минимума глубин для гарантированного запаса безопасности). При отсутствии локального растра доступен встроенный синтетический демо-режим.
- **Динамический запас под килем (DUKC)**: Расчет скоростного проседания судна на мелководье по открытой формуле Баррасса ($\Delta h = \frac{C_b \cdot V^2}{100}$) в реальном времени с учетом статической осадки, скорости хода и нормативного запаса UKC.
- **Оптимизация фарватеров**: Поиск пути алгоритмом $A^*$ со штрафной функцией мелководья и прибрежного коридора, дополненный сглаживанием прямой видимости (алгоритм Брезенхема с ограниченным горизонтом для сохранения макроструктуры пути).
- **Навигационная геодезия**: Точный расчет ортодромических дистанций по формуле Haversine (в морских милях, NM) и времени перехода (ETA).
- **Интерактивный интерфейс ECDIS**: Темная консоль управления на MapLibre GL и Chart.js с динамическим профилем вертикального сечения морского дна по всей длине маршрута, выбором профилей судов и отображением координат в формате градусы/минуты (DMM).

## Гидродинамические формулы и функция стоимости

### 1. Скоростное проседание судна (Squat Effect)
Проседание корпуса судна на ходу в открытой воде рассчитывается по эмпирической зависимости Баррасса:

$$\Delta h = \frac{C_b \cdot V^2}{100}$$

Где:
- $\Delta h$ — динамическое проседание (в метрах);
- $C_b$ — коэффициент общей полноты корпуса (Block Coefficient, по умолчанию $0.60$);
- $V$ — скорость относительно воды (в узлах).

Минимальная безопасная глубина акватории:

$$D_{\text{min}} = T_{\text{static}} + \Delta h + \delta_{\text{UKC}}$$

### 2. Функция стоимости перемещения
Стоимость перехода между соседними ячейками сетки штрафует приближение к опасной изобате и неоправданный выход в глубоководную открытую часть моря:

$$C = C_0 \cdot \left( 1.0 + \frac{8.0}{D - D_{\text{min}}} + P_{\text{deep}} \right)$$

Где:
- $C_0$ — базовая евклидова стоимость шага (1.0 для кардинальных направлений, $\sqrt{2}$ для диагоналей);
- $D$ — глубина ячейки по данным батиметрии (в метрах);
- $D_{\text{min}}$ — минимальная требуемая глубина для безопасного прохода;
- $P_{\text{deep}}$ — штраф за выход в открытое море на глубинах свыше 150 м.

## Установка и запуск

### Требования
- Python 3.10+
- Среда с поддержкой C-библиотек GDAL для `rasterio`

### 1. Клонирование и настройка виртуального окружения
```bash
git clone https://github.com/<ваш-логин>/sounder-path.git
cd sounder-path

python -m venv venv
# Windows (PowerShell):
.\venv\Scripts\Activate.ps1
# Linux / macOS:
source venv/bin/activate

pip install -r requirements.txt
```

### 2. Подготовка батиметрических данных
Поместите файл регионального растра GeoTIFF (например, тайл EMODnet DTM `E8_2024.tif`) в директорию `data/raw/`:
```bash
# При необходимости перегенерации растрового оверлея карты:
python generate_heatmap.py --scale-factor 4
```

### 3. Запуск навигационного сервера
```bash
uvicorn backend.main:app --host 0.0.0.0 --port 8000 --reload
```

Откройте веб-браузер по адресу `http://localhost:8000`.

## API сервиса

### `POST /api/route`
Расчет безопасного маршрута между двумя точками с учетом гидродинамики.

**Тело запроса (JSON):**
```json
{
  "start_lon": 33.50,
  "start_lat": 44.62,
  "goal_lon": 33.40,
  "goal_lat": 45.18,
  "draft": 1.2,
  "speed_knots": 10.0,
  "ukc": 0.5
}
```

**Ответ:**
Возвращает объект GeoJSON `Feature` (геометрия `LineString`), содержащий:
- `properties.distance_nm`: общая дистанция пути в морских милях;
- `properties.eta_hours`: расчетное время перехода в часах;
- `properties.min_clearance_m`: минимальный зарегистрированный запас под килем на маршруте;
- `properties.waypoints`: количество поворотных точек;
- `profile`: непрерывный массив промеров глубин и клиренса вдоль линии пути.

### `GET /api/grid`
Возвращает полигон границ покрытия загруженной батиметрии в формате GeoJSON.

### `GET /api/health`
Проверка работоспособности сервиса и размеров загруженной матрицы.
